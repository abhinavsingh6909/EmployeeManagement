# Employee Management System

A simple web application to manage employee records with CRUD operations, search, filter, and pagination.

## Technologies Used

- **Frontend:** React, Bootstrap, Axios
- **Backend:** Node.js, Express.js
- **Database:** JSON file (employees.json) using Node.js (fs) module

# How to Install and Run

# 1. Backend

In terminal:

```bash
cd backend
npm install
node server.js
```

# 2. Frontend

Open a second terminal in VS Code:

```bash
cd frontend
npm install
npm run dev
```
